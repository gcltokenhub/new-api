# CR-001：以《Token平台开发计划》覆盖一期基线

- 状态：已确认
- 日期：2026-09-15
- 变更类型：范围、技术基座、交付阶段与部署规划调整
- 决策来源：[《Token平台开发计划》](https://my.feishu.cn/wiki/QYJlwCyU7iQpWkkAaBechCmznXe)
- 关联来源：[来源核验记录](../requirements/sources.md)

## 决策

用户指定《Token平台开发计划》作为此前规划的补充和覆盖来源。即日起，当前一期的实施基线为[一期平台基础版 PRD](../requirements/v1-platform-foundation-prd.md)，目标是在 2026 年 9 月底形成可运行的 Token 平台：原生 New-API 核心能力可用，并完成 P0 品牌与门户/控制台界面改造。

此前定义的“企业租户 → 项目 → 模型开通 → 项目额度 → 项目 API Key → 调用 → 用量/成本/日志/告警”闭环不再作为当前一期承诺，转为后续企业产品层蓝图，保留在 [v1-prd.md](../requirements/v1-prd.md)。

## 覆盖项

| 项目 | 原基线 | 当前基线 |
| --- | --- | --- |
| 上游基座 | New-API，未锁定具体上游仓库 | `QuantumNous/new-api`，Go 后端与 React 前端，AGPLv3；实施前必须固定 tag/commit 并完成许可证审查 |
| 一期目标 | 内部企业项目闭环 | 原生 New-API 平台能力 + P0 UI + 多环境部署基础 |
| P0 UI | 企业项目控制台为主 | 品牌、门户首页、控制台总览、Token 管理 |
| 部署路径 | 本地开发后部署华为云 ECS | 开发单机 Compose、预发三节点模拟、生产物理 GPU 推理资源与华为云 New-API 集群的混合规划 |
| 路由辅助 | 未定义 | CC-Switch 可作为本地 AI 编程工具路由控制层；生产计量与计费仍以 Token 平台为准 |

## 当前一期范围

1. 固定并导入上游源码基线，保留渠道、Token、转发、日志、限流、用户等原生核心能力。
2. 按 Figma 实现品牌基础和门户首页；实现控制台总览与 Token 管理的 P0 页面。
3. 建立开发、预发和生产部署配置的可验证方案，满足多节点共享配置、会话与缓存约束。
4. 形成基础监控、日志和运行证据；不把规划中的主机、地址或凭据写入版本库。

## 后续路线

## 约束与待确认项

- 上游快照已固定，详见[上游基线记录](../architecture/upstream-baseline.md)；在源码导入、构建和主链路测试完成前，不得宣称已完成复用或兼容性验证。
- CC-Switch 是本地开发工具的路由控制层，不替代生产网关；生产接入方式需单独设计评审。
- 物理 GPU、华为云资源、网络连通、安全边界、备份恢复目标和实际模型/渠道名单均需在实施前确认。
- 本变更只更新文档基线，不代表代码、基础设施或生产环境已经交付。
