## 门户逐段实现约束（2026-09-15 纠正）

对应 TF-103 / AT-103。Figma `31:2` 是视觉参考，不能作为运行时整页图片。导航、首屏、算力展示、模型展示、企业服务、底部接入和页脚须分别使用语义化 DOM；首屏右侧架构插画可用独立图片，左侧正文和操作保留真实 DOM。不得用透明热点覆盖截图模拟可点击页面。

入口映射以当前源码路由为准：模型广场 `/pricing`，模型体验 `/playground`，控制台 `/dashboard`，访客接入 `/sign-up`；认证和模块开关继续由原生路由守卫处理。产品、算力与解决方案使用页内锚点；开发者接入区块及其导航暂时隐藏。进入模型体验后由用户选择实际可用模型，展示卡不假定模型已开通。

2026-09-17 认证页视觉更新：`/sign-in` 采用设计稿“登录”的双栏品牌与表单布局；`/sign-up` 采用“申请开通”视觉，明确作为现有账号注册入口。注册仅保留当前接口支持的用户名、密码、确认密码及按配置启用的邮箱验证等字段，不展示企业名称、联系人、电话，也不表示存在企业申请审批流程。安全验证、第三方入口及原路由守卫保持原行为。Figma 连接器配额受限，本次以用户提供的双页截图为视觉依据，非逐节点精确验收。

2026-09-18 登录成功后未指定返回地址时默认进入 `/playground`（本地开发服务为 `http://127.0.0.1:5173/playground`）；带有合法 `redirect` 参数时仍返回原目标。已登录用户访问登录页及第三方登录回调采用相同默认目标；模型体验模块的原有权限与开关守卫继续生效。

2026-09-18 注册完成后使用本次填写的用户名和密码调用现有登录接口；成功后沿用会话建立与二次验证流程进入控制台。自动登录请求失败时提示账号已创建并转入登录页。注册与登录接口均启用 Turnstile 时，注册阶段的令牌不能重复用于登录，因此仍可能需要在登录页重新完成验证。

2026-09-18 门户文案调整：简体中文导航“产品服务”改为“产品”；底部横幅按钮改为“联系我们”。按用户确认，本轮保留按钮暂无点击行为的现状，联系功能后续接入；其他注册和控制台入口保持原映射。

首页模型展示卡暂只静态列出 DeepSeek、Qwen、GLM、Doubao、Kimi 品牌，不调用模型广场接口、不展示具体型号；保留场景描述，按 2026-09-18 用户要求移除各卡片的“可用性及价格以模型广场为准”提示，并扩充 Qwen 说明至两行。说明文字与体验按钮之间保留至少 25px 间距。实际可用型号、价格、上下文和能力以平台模型广场为准。算力区与企业服务区原先不发布设计示例中的延迟、机房运行状态、容量、SLA 或服务时长承诺；2026-09-17 用户明确要求将“稳定供给”区块的节点状态、延迟、容量和 SLA 文案作为真实服务指标发布，该区块按后续决定执行，其他区块仍遵守原边界。

2026-09-18 用户要求模型区移除“热门模型 / 文本模型 / 多模态”分类切换，保留五张静态模型卡，将“查看模型广场与价格”入口移到标题右侧原分类位置，仍跳转 `/pricing`。

复用检查：`PublicHeader` / `PublicNavigation` 的导航会被后台动态菜单覆盖，且未提供满足本页布局的插槽与页内锚点渲染；`MobileDrawer` 含控制台账户菜单。因此门户使用专属语义化导航布局，通用按钮复用 `Button`，不新增通用弹层或导航状态系统。原 `HeroButtons` 仅覆盖控制台与注册登录入口，无法表达首屏体验和产品锚点的组合。自定义首页继续保留原 `PublicLayout` 和富文本渲染路径。

接口边界：仍使用 `GET /api/home_page_content` 读取管理员配置；本次无新增接口、字段或认证规则。空配置进入逐段门户，已有 Markdown、HTML 和 URL 自定义首页沿用原处理。逐段门户的文案来自 i18n 资源，入口集中于导航配置；完整后台逐字段编辑不计为本次已交付。

“稳定供给”区块按 Figma `31:106` 实现：深色背景、标题与节点入口、华西/华东/海外三张节点卡及各自的区域插图、右侧供给网络卡；前三张节点卡背景按 2026-09-18 用户截图要求统一为 `#f2f7ff`。节点数值与状态来自用户本次确认的设计稿，当前为静态发布内容，不是实时遥测。节点入口锚定本页节点卡列表，未新增独立节点路由。

2026-09-18 按用户要求调整三张节点卡的地点文案：华西算力中心为“乌兰察布 / 和林格尔”，华东数据中心为“上海 / 苏州 / 杭州”，海外合作节点为“马来西亚 / 印度尼西亚”。
